# Online Job Portal

## About the Project

The Online Job Portal is a full-stack web application developed using Java, Spring Boot, MySQL, HTML, CSS, and JavaScript. It provides a simple interface for adding job listings and viewing available jobs. The application connects the frontend with the backend through REST APIs and stores job details in a MySQL database.

## Features

* **Add Job Listings:** Add new jobs with details such as job title, company name, location, and description.
* **View Available Jobs:** Display available job listings through a simple web interface.
* **Database Integration:** Store and retrieve job information using MySQL.
* **REST API Integration:** Connect the frontend and backend for smooth communication.
* **Simple User Interface:** Provide an easy-to-use interface for managing job listings.

## Technologies Used

* **Programming Language:** Java
* **Backend Framework:** Spring Boot
* **Frontend:** HTML, CSS, JavaScript
* **Database:** MySQL
* **Data Access:** Spring Data JPA
* **Build Tool:** Maven
* **Version Control:** Git and GitHub

## How It Works

1. Users interact with the frontend to add or view job listings.
2. The frontend sends requests to the backend through REST APIs.
3. The Spring Boot controller handles incoming requests.
4. The repository layer uses Spring Data JPA to interact with the MySQL database.
5. Job details are stored or retrieved and displayed on the webpage.
